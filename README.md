# Structures de données en C : cours et exercices corrigés

Code de la série **« Structures de données en C »** de la chaîne
[IT Skills Maker](https://www.youtube.com/@ItSkillsMaker) :
[la playlist](https://www.youtube.com/playlist?list=PLOVndt9X-BM4).

Chaque opération est écrite **deux fois** : avec une boucle (`_iter`) et en récursif (`_rec`).
Tout le code est compilé avec `-Wall -Wextra -Werror` et exécuté, et les sorties réelles sont dans
`preuves/`.
